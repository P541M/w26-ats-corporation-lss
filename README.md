# W26 Work Term Report — ATS Life Sciences Systems

Work term report for my Winter 2026 co-op placement as a **Toolset Software Developer Co-op** at ATS Corporation's Life Sciences Systems division in Cambridge, Ontario.

Built with [Next.js](https://nextjs.org), [Tailwind CSS v4](https://tailwindcss.com), and [TypeScript](https://www.typescriptlang.org).

## Overview

A single-page report covering:

- **Company Profile** — ATS Corporation and the Life Sciences Systems division
- **Job Description** — Role responsibilities, skills, and projects shipped
- **Learning Goals** — Five co-op learning goals with action plans and reflections
- **Conclusion** — Key learnings and what comes next
- **Acknowledgements** — The people who made the term possible

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
